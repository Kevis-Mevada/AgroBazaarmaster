# 🌾 Agro-Bazaar - E-Commerce Platform for Farmers

An online e-commerce platform that enables a farmer to buy or sell anything related to agriculture and farming. This platform is strictly dedicated to farmers to help them generate good profitable revenue.

## 🔴 LIVE DEMO
**Live:**
**[https://agrobazaar.gamer.gd/](https://agrobazaar.gamer.gd/)**

---

## 🎯 The Problem & Our Solution

Every day new technology is arriving, but farmers are still lacking in benefitting from the internet. This idea is completely dedicated to farmers.

Our platform connects farmers directly with buyers and other farmers, allowing them to:
* **Sell** their agricultural products for a good, profitable revenue.
* **Buy** farming-related goods.
* Eliminate middlemen and gain control over their sales.

## ✨ Key Features

* **Farmer-Only Vendors:** Strictly all vendors are farmers, as the platform is dedicated to them.
* **Easy to Use:** Designed to be as familiar as social media accounts.
* **Secure Payments:** Integrated with a safe payment gateway (Razorpay).
* **Logistics Support:** Includes a good logistic delivery partner to help farmers do business from home.

## 💻 Technology Stack

* **Backend:** Core PHP (PDO)
* **Database:** MySQL
* **Frontend:** HTML5, CSS3, Bootstrap
* **Payment Gateway:** Razorpay API Integration

## 🚀 How to Run Locally

1.  Clone this repository:
    ```bash
    git clone [https://github.com/Kevis-Mevada/AgroBazaarmaster.git](https://github.com/Kevis-Mevada/AgroBazaarmaster.git)
    ```
2.  Place the project in your XAMPP/WAMP `htdocs` folder.
3.  Go to `localhost/phpmyadmin` and create a new database.
4.  Import the `database.sql` file (if you have one) into your new database.
5.  Update your `config.php` (or `db.php`) file with your local database credentials (e.g., user: 'root', pass: '').
6.  Open `localhost/AgroBazaarmaster` in your browser.
